TLV 字段

      输入格式与适用范围

      支持最多 254 字节的 OpenThread Operational Dataset，按 1 字节 Type、1 字节 Length 和 Length 字节 Value 拆分。支持连续 HEX、空格、冒号、逗号分组与 0x 前缀。检查截断、重复 TLV、常见字段长度、UTF-8 名称和 Channel Mask 子条目；未知类型保留原始值。

      Security Policy 展示密钥轮换小时数与原始 flags，不跨 Thread 版本解释权限位。Timestamp 显示 seconds / ticks / authoritative，不当作日期。完整性提示只检查常见 Active / Pending 字段是否存在；结构检查通过不代表网络可达、密钥正确或设备一定能入网。

      字段依据 OpenThread Operational Dataset API 与 MeshCoP TLV 定义。敏感值不进入 URL 或存储；离开页面清空。
