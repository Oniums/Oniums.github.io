未启用自动保存

只记录启用后的真实串口数据，不回填缓存或演示。暂停画面、筛选和清屏不影响自动保存；取消勾选或断开串口会完成最后一笔提交。文本按行记录，未换行内容在提交时标记为“片段”；原始模式逐字节保存 RX，不含时间戳或 TX。

单文件模式追加已有内容；按时间模式在所选目录生成带 UTC 时间、会话标识和序号的新文件，遇到重名会另取名字。请勿同时用其他程序编辑。状态中的“已提交”表示写入流已关闭成功。强制关闭网页、浏览器崩溃或休眠可能丢失尚未提交的数据，离开前请取消勾选并等待“保存已结束”。例如 10:20 启用、间隔 60 分钟，会在约 11:20、12:20 切换文件，并非整点切换。后台调度可能推迟切换，恢复后不补建休眠期间的空白文件。大文件频繁提交可能变慢，可缩短分文件间隔。

保存与导出

导出当前缓存。文本导出遵循显示选项与筛选；HEX 模式导出完整缓存中的匹配 HEX 行。BIN 不加时间戳、不转换编码；JSON 保留每块方向、接收 / 发送时间与 HEX。清空或刷新后缓存无法恢复，长时间采集可开启自动保存。

转义支持 \r、\n、\t、\\ 与 ASCII 范围的 \xNN。HEX 模式输入原始字节；切换时不会自动改写内容。

定时发送

使用启动时的内容与结束符；上一笔写入完成后再等待间隔，不并发堆积。断线或发送失败即停止。浏览器定时不保证精确周期。

使用说明与能力边界

优先使用桌面 Chrome / Edge，通过 HTTPS 或 localhost 打开。网页只访问你授权的本机串口，不访问远程主机。手机及不支持 Web Serial 的浏览器仍可体验演示。页面不上传串口数据，不写入 localStorage / IndexedDB。自动保存默认关闭，仅在你选择并授权的本地文件或目录中记录；命令不自动保存。

时间戳为浏览器观察到数据的本地时间，不是设备硬件时间戳。USB 和系统会合并数据，HEX 分块不代表协议帧。文本按 CR / LF 分行，超长行每 4,096 字符拆分；控制字符按显示选项处理，不提供完整 VT100 终端仿真。暂停画面仍继续接收并受缓存上限约束；关闭网页、电脑休眠或拔出设备会中断采集。

发送完成表示浏览器写入操作完成，不等于设备已执行命令。串口断开后，未结束的文本行会补入记录。Framing / Parity 等读取告警在浏览器提供新读流时尝试继续接收；告警位置可能缺失字节，同类提示按计数合并，不代表错误已被修复。文本保存会标记接收中断，原始 BIN 只保留实际收到的字节。正常的 NUL（0x00）不会被当作读取错误；默认隐藏，可勾选“控制字符可见”显示为 <00>。若适配器不支持所选波特率、流控或信号线，页面会显示操作错误。
