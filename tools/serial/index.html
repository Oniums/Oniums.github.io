自动保存到本地文件

未启用自动保存

只记录启用后的真实串口数据，不回填缓存或演示。暂停画面、筛选和清屏不影响自动保存；取消勾选或断开串口会完成最后一笔提交。文本按行记录，未换行内容在提交时标记为“片段”；原始模式逐字节保存 RX，不含时间戳或 TX。

单文件模式追加已有内容；按时间模式在所选目录生成带本地时间及其时区偏移、会话标识和序号的新文件，遇到重名会另取名字。请勿同时用其他程序编辑。状态中的“已提交”表示写入流已关闭成功。强制关闭网页、浏览器崩溃或休眠可能丢失尚未提交的数据，离开前请取消勾选并等待“保存已结束”。例如 10:20 启用、间隔 60 分钟，会在约 11:20、12:20 切换文件，并非整点切换。后台调度可能推迟切换，恢复后不补建休眠期间的空白文件。大文件频繁提交可能变慢，可缩短分文件间隔。

保存与导出

导出当前缓存。文本导出遵循显示选项与筛选；HEX 模式导出完整缓存中的匹配 HEX 行。BIN 不加时间戳、不转换编码；JSON 保留每块方向、接收 / 发送时间与 HEX。清空或刷新后缓存无法恢复，长时间采集可开启自动保存。

测试会话与曲线

本地记录 · 手动结束后判断

为一次操作命名，记录标记与完整接收行。只保留最近一次会话；开始新会话会替换旧记录，请先导出。刷新页面会丢失会话。

区分大小写、纯文本包含匹配，最多各 20 条。仅检查会话内完整 RX 行；发送内容、手动标记、显示筛选与清屏不参与判定。先开始会话，再手动执行设备操作；会话按钮不会发送命令。

未开始会话

    开始会话后，识别 !p 毫秒计数 名称=数值。
    格式、容量与判定说明

    曲线示例：!p 1000 temperature=25.6 battery=3.12。通道名为 1–32 个 ASCII 字符，以字母或下划线开头，可包含数字、点、短横线；数值支持整数、小数和科学计数法。横轴使用设备毫秒计数；计数回退会分段，只画当前通道最后一段。设备标记支持 !m @1000 按键触发 或 !m 按键触发，列表按浏览器接收时间排列。

    会话保留最近 2,000 行且最多 1 Mi 字符、100 条标记、8 个通道且每通道 600 点。曲线与标记独立淘汰，导出含淘汰计数；接收行淘汰、读取错误、后台切换、断开或不完整行会阻止“通过”。未配置条件时只记录；空数据不通过。检查结果仅表示本次日志满足所填条件，不等于设备功能验收。结束前仍为观察中，避免漏掉稍后出现的错误。

    功能思路与 !p / !m 文本格式参考 dwatman / MCUscope（MIT）。本站独立实现浏览器版本，仅支持上述文本子集。阅读设计与使用说明 →

    使用说明与能力边界

    优先使用桌面 Chrome / Edge，通过 HTTPS 或 localhost 打开。网页只访问你授权的本机串口，不访问远程主机。手机及不支持 Web Serial 的浏览器仍可体验演示。页面不上传串口数据，不写入 localStorage / IndexedDB。自动保存默认关闭，仅在你选择并授权的本地文件或目录中记录；命令不自动保存。

    网页、文件名、自动保存及导出统一使用浏览器本地时间并标注时区偏移（如 +08:00，文件名为 +0800）。文件名记录文件创建或导出的时间，日志记录浏览器观察到数据的时间，不是设备硬件时间戳。USB 和系统会合并数据，HEX 分块不代表协议帧。文本按 CR / LF 分行，超长行每 4,096 字符拆分；控制字符按显示选项处理，不提供完整 VT100 终端仿真。暂停画面仍继续接收并受缓存上限约束；关闭网页、电脑休眠或拔出设备会中断采集。

    发送完成表示浏览器写入操作完成，不等于设备已执行命令。串口断开后，未结束的文本行会补入记录。Framing / Parity 等读取告警在浏览器提供新读流时尝试继续接收；告警位置可能缺失字节，同类提示按计数合并，不代表错误已被修复。默认勾选“隐藏接收告警日志”，日志窗口、复制和筛选文本导出不显示这类 SYS 摘要；取消勾选可恢复查看。顶部告警提示与计数、自动保存中的告警摘要，以及停止接收等错误提示始终保留。文本保存会标记接收中断，原始 BIN 只保留实际收到的字节。正常的 NUL（0x00）不会被当作读取错误。文本视图默认隐藏仅含 NUL 的接收行；取消“隐藏纯 NUL 接收行”并勾选“控制字符可见”可显示为 <00>。该过滤同时适用于复制和筛选文本导出，不影响 HEX 视图、告警计数、原始导出及自动保存；含正常文字的行仍然保留。若适配器不支持所选波特率、流控或信号线，页面会显示操作错误。
