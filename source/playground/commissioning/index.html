演示范围与参考资料
本页演示经典 BLE 辅助的 Matter over Thread 首次配网主干，合并了部分读属性、监管配置及响应消息；不是完整协议一致性测试。手机在此承担 Commissioner 与 Controller，边界路由器同时承担 SRP Server 和本示例的 Thread 父节点。真实部署中这些角色可以拆分，父节点也可能是其他 Thread Router。
三个场景的消息、故障与 App 文案均为教学构造；服务发现异常具体模拟“SRP 注册已成功，但手机侧未解析到运行服务”。失败演示止于本次超时，未继续播放 Fail-safe 到期回滚，也不表示凭据会永久保留。订阅作为配网后的业务验证单独展示。
参考：Google Matter commissioning primer · OpenThread IPv6 与服务发现实验。动画按教学节奏播放，时长与重试次数不代表协议规定。
