整数、浮点和位域怎样解释？

整数采用固定位宽，负数按二进制补码解释；64 位整数使用 BigInt，避免超过 JavaScript 安全整数范围时丢精度。浮点使用 IEEE 754 binary32 / binary64，可能出现 NaN、Infinity 或负零。位域始终从原始位模式提取。

字节序决定多字节数值的组合方式，不改变每个字节内的位顺序。读取偏移从 0 开始；例如 01 02 按 uint16 小端为 513，大端为 258。
